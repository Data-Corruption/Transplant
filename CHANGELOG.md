# Changelog

## [v0.1.0] - 2026-09-05

Initial release. Grow your own Sprout <3

### Added

- Interactive Linux/WSL setup wizard with flags for scripted use.
- Feature selection, project configuration, and finalization through the
  checkout's own Sprout cutter, with compatibility checks and a preview.
- README setup, copyright notices, and a choice of what docs to keep.
- Automatic tests and a dev build, plus optional setup branch and commit.
- Per-user installation and signed updates with `transplant update`.
- Linux and Windows binaries for amd64 and arm64. On Windows, the wizard
  points you to WSL; installation and update commands work natively.
